# Contributing to Token Doctor

Thank you for your interest in contributing to Token Doctor!

## How to Contribute

1. **Fork the Repository** on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/cursor-rules-support
   ```
3. **Commit your Changes**:
   ```bash
   git commit -m "feat: add support for Cursor .cursorrules diagnosis"
   ```
4. **Push to the Branch**:
   ```bash
   git push origin feature/cursor-rules-support
   ```
5. **Open a Pull Request**.
